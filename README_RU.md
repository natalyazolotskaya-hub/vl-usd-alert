# Telegram-бот мониторинга курса USD на VL.ru

## Что делает
- Проверяет курс **продажи USD банками** на `https://www.vl.ru/dengi/`.
- Ищет минимальное найденное значение среди банков.
- Уведомляет, когда курс становится **строго ниже 80 ₽**.
- Не повторяет уведомление, пока курс остаётся ниже порога.
- Если курс снова становится 80 ₽ или выше, бот вооружается для следующего уведомления.
- Проверяет страницу каждые 10 минут.

## Важное ограничение
VL.ru может менять HTML-разметку или загружать курсы динамически. Парсер в `bot.py` намеренно работает осторожно: если он не может уверенно извлечь данные, он не отправляет ложное уведомление. После первого запуска проверьте логи. Если в них регулярно появляется «Не удалось уверенно извлечь курсы», потребуется адаптировать парсер под текущую HTML-структуру сайта. Не используйте бота для финансовых решений без проверки курса непосредственно у банка: фактический курс и наличие валюты могут отличаться.

## 1. Создать Telegram-бота
1. Откройте Telegram и найдите `@BotFather`.
2. Отправьте `/newbot`.
3. Задайте имя и username бота.
4. Скопируйте выданный токен. **Не отправляйте токен в этот чат и никому его не показывайте.**

## 2. Установить на компьютер или сервер
Нужен Python 3.10 или новее.

Распакуйте архив, откройте терминал в папке проекта и выполните:

```bash
python -m venv .venv
```

Windows:
```powershell
.venv\Scripts\Activate.ps1
```

macOS/Linux:
```bash
source .venv/bin/activate
```

Затем:
```bash
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и внесите токен:
```env
BOT_TOKEN=ваш_токен
CHAT_ID=
THRESHOLD=80
CHECK_INTERVAL_MINUTES=10
```

## 3. Узнать chat_id
1. Запустите `python bot.py`.
2. Откройте своего нового бота в Telegram и нажмите Start или отправьте `/start`.
3. Бот ответит числом `chat_id`.
4. Остановите процесс, впишите это число в `.env` в строку `CHAT_ID=`.
5. Запустите `python bot.py` снова.
6. Отправьте `/test` — должно прийти тестовое сообщение.
7. `/status` показывает настройки.

## 4. Постоянная работа
Для работы 24/7 проект нужно разместить на постоянно работающем компьютере или VPS. Если закрыть терминал на обычном компьютере, бот остановится. Для Linux-сервера можно оформить запуск через `systemd` (пример ниже).

Создайте `/etc/systemd/system/vl-usd-bot.service`:

```ini
[Unit]
Description=VL.ru USD Telegram monitor
After=network-online.target

[Service]
WorkingDirectory=/opt/vl-usd-telegram-bot
ExecStart=/opt/vl-usd-telegram-bot/.venv/bin/python /opt/vl-usd-telegram-bot/bot.py
Restart=always
RestartSec=10
User=ubuntu

[Install]
WantedBy=multi-user.target
```

Затем:
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now vl-usd-bot
sudo systemctl status vl-usd-bot
```

## Настройки
В `.env`:
- `THRESHOLD=80` — порог в рублях.
- `CHECK_INTERVAL_MINUTES=10` — период проверки.
- `SOURCE_URL` — адрес страницы VL.ru.
- `TIMEZONE=Asia/Vladivostok` — часовой пояс отметки времени.

## Примечания
- Условие именно `< 80`, а не `<= 80`.
- Бот мониторит опубликованные на VL.ru курсы продажи банков, а не курс ЦБ.
- Токен храните только в `.env`; не публикуйте его и не добавляйте `.env` в общедоступный репозиторий.
- Учитывайте правила и ограничения сайта при автоматическом обращении к нему.
